## What changed in v5
- Course: 5 CEFR levels (A1, A2, B1, B2, C1) x 10 units x 5 lessons = 250 lessons (`curriculum.js`, `lvnew.js`, `lv01-lv20.js`).
  206 lessons come from the first course (re-ordered by topic and difficulty), 44 were written new (`lvnew.js`). 7 new grammar rules are in `curriculum.js`.
- Lesson = 8 steps + a check (Warm-up, Words, Grammar, Listening, Reading, Speaking, Writing, Practice, Lesson check 80%).
- Every lesson has its own Workbook (opens after the lesson check). Unit test: 20 questions, Final Level Exam: 40 questions, pass mark 80%.
- Placement test (adaptive) maps to A1-C1. Old progress from the 30-level course is reset once (words, streak and settings are kept).
- New interface in `ui.js`, `ui2.js`, `art.js` and the "v5" block at the end of `style.css`. Photos/3D art come from the two reference screens (`hero.jpg`, `thumb.jpg`, `ic-*.png` ...), re-branded with the Languway mark.
- Settings are cards that open an inner page. "Features and how to use them" explains every feature.
- Translator: usage explanation (noun/verb/adjective rules, past forms) and an online photo from Wikipedia for nouns.

## Known limits
- No IPA transcription (no offline source). Pronunciation = normal and slow audio.
- Word pictures inside lessons are still the old emoji tiles when offline; a real photo replaces them when online.
- Content should be reviewed by an English teacher before publishing.

# LanguWay English

A free, offline-capable English course (A1 to C1) built as a flat-folder PWA. No build step, no paid services.

## Structure

|---|---|

| `style.css` | All styles (colour tokens in `:root`, dark mode via `[data-d]`) |
| `app.js` | Application logic (see the section index at the top of the file) |
| `story.js` | Story player: SVG scenes, text-to-speech voices, subtitles, questions |

## Course layout
30 levels. Levels 1-20 have 2 units, levels 21-30 have 4 units; every unit has 3 lessons, a grammar rule and a 15-question test. Every level ends with a 30-question test (pass mark 75%). Plan: about 14 days per level. Level 21 opens with an optional review of levels 1-20.

## Data and updates
Progress lives in `localStorage` (key `ef2_<user>`) and, when signed in, in Supabase. `clean()` validates and migrates saved data (old 20-level saves are converted automatically); `mergeS()` merges two copies without losing progress. Updates are installed only when the learner agrees.

## Content rules
No music, no inappropriate content; characters are faceless, men wear long modest clothes, women wear hijab and a long dress.

## Tutor
The "Tutor" notes after each answer are rule-based (definitions, the evidence sentence from the text, a word-by-word comparison, grammar rules). They are not generated by an AI model and work offline.

## Running it on a computer (for you or for users)
1. **Quickest:** open the site address in Chrome or Edge. Click the install icon in the address bar to use it like a program (works offline after the first visit).
2. **Locally from the folder:** the app must be served over http, not opened by double-click. In the folder run `python3 -m http.server 8000` (or `npx serve`), then open `http://localhost:8000`.
3. **Hosting:** upload the whole flat folder to GitHub Pages or Netlify. Bump `CACHE` in `sw.js` on every release.
4. Cloud sign-in needs internet. Guests and signed-in learners can study offline; progress syncs when the connection returns.
5. Sign-out keeps your progress in your account. Only "Delete account" removes it.


## v23 (English-only)
- The whole site is in English. Only the **Translator** uses another language: the learner picks it (Arabic, French, Spanish, Turkish, Urdu and more) at the top of the Translator page; the choice is remembered on the device.
- `phrases.js`: Phrases and Idioms (idioms, everyday expressions, phrasal verbs, quiz).
- The placement test is asked only when opening Learn (or Grammar lessons). Home, Settings, Translator, Explore, Stories and Phrases open without it. A complete beginner can start at Level 1.
- Learn shows CEFR bands (A1, A2, B1, B2, C1).
- The opening splash lasts 3 seconds (tap to skip).


## Certificates (v25)
- A certificate for each level (all lessons, unit tests and the level test at 75% or more) and a full-course certificate after all 30 levels.
- Signed-in learners get a unique code (LW-XXXX-XXXX-XXXX) created and stored on the server by the `issue_certificate` function, which checks the saved progress first. Anyone can check a code in Certificates, Verify a certificate (`verify_certificate`).
- The printed page has a seal, a guilloche pattern, microtext and the code. Honest limit: progress is stored from the browser, so the server record proves who was issued a code and when, not that a person truly learned the material.

## Pictures
`wpic.js` gives each word an emoji picture that works offline (lessons, review, notebook, helper, Translator). Abstract words use a symbolic emoji.
