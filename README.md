# LanguWay English

A free, offline-capable English course (A1 to C1) built as a flat-folder PWA. No build step, no paid services.

## Structure
| File | Purpose |
|---|---|
| `index.html` | Page shell, security headers (CSP), splash markup, script/style links |
| `style.css` | All styles (colour tokens in `:root`, dark mode via `[data-d]`) |
| `app.js` | Application logic (see the section index at the top of the file) |
| `story.js` | Story player: SVG scenes, text-to-speech voices, subtitles, questions |
| `stories.js` | 30 "Cedar City" episodes (4 scenes each, English + optional Arabic subtitles) |
| `dict.js`, `dict2.js` | Translator data: dictionary, phrases, idioms, phrasal verbs, synonyms, irregular verbs |
| `explore.js`, `translate.js` | Explore section (word of the day, extra lessons, writing, weekly rule, role-play, career English, picture questions) and the Translator |
| `pics.js` | 24 illustrated picture questions |
| `defs.js` | English definitions for all 1101 vocabulary words |
| `levels.js`, `lv01.js`...`lv20.js` | Lesson content |
| `grammar.js`, `grammar2.js` | 80 grammar rules |
| `scenes.js` | Anime-style story backgrounds (8 places x 4 times of day, hand-coded SVG) |
| `coach.js` | Smart coach (bilingual EN/AR reminders from your progress and what you use), bilingual helper brain, quick-access tiles, bottom bar. Usage memory lives in its own key `ef_use_<user>`; it never touches saved progress |
| `videos.js` | Optional YouTube ids per lesson |
| `supabase-config.js` | Supabase URL and publishable key |
| `sw.js`, `manifest.json` | Offline cache and install manifest (bump `CACHE` in `sw.js` every release) |
| `SUPABASE_SETUP.sql` | Run once in Supabase SQL Editor (progress table, RLS, delete-account function) |

## Course layout
30 levels. Levels 1-20 have 2 units, levels 21-30 have 4 units; every unit has 3 lessons, a grammar rule and a 15-question test. Every level ends with a 30-question test (pass mark 75%). Plan: about 14 days per level. Level 21 opens with an optional review of levels 1-20.

## Data and updates
Progress lives in `localStorage` (key `ef2_<user>`) and, when signed in, in Supabase. `clean()` validates and migrates saved data (old 20-level saves are converted automatically); `mergeS()` merges two copies without losing progress. Updates are installed only when the learner agrees.

## Content rules
No music, no inappropriate content; characters are faceless, men wear long modest clothes, women wear hijab and a long dress.

## Tutor
The "Tutor" notes after each answer are rule-based (definitions, the evidence sentence from the text, a word-by-word comparison, grammar rules). They are not generated by an AI model and work offline.

## Running it on a computer (for you or for users)
1. **Quickest:** open the site address in Chrome or Edge. Click the install icon in the address bar to use it like a program (works offline after the first visit).
2. **Locally from the folder:** the app must be served over http, not opened by double-click. In the folder run `python3 -m http.server 8000` (or `npx serve`), then open `http://localhost:8000`.
3. **Hosting:** upload the whole flat folder to GitHub Pages or Netlify. Bump `CACHE` in `sw.js` on every release.
4. Cloud sign-in needs internet. Guests and signed-in learners can study offline; progress syncs when the connection returns.
5. Sign-out keeps your progress in your account. Only "Delete account" removes it.
